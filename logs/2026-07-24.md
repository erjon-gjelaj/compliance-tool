# 2026-07-24

## Task 001 — Scaffold Next.js project

Set up the project skeleton so there's something to build the landing page on.

What I did:

- Created a Next.js App Router project with TypeScript, ESLint, Tailwind CSS v4,
  and a `src/` directory. Next.js 16.2.11, React 19.
- Renamed the package to `certloop` and added `src/lib/constants.ts` holding
  `SITE_NAME`, `SITE_TAGLINE`, `SITE_URL`, and `CONTACT_EMAIL`. Everything that
  shows a brand name reads from there, so renaming later is a one-line change.
- Added `.env.local.example` as a template. Confirmed `.gitignore` already
  ignores `.env*`, so no secrets can be committed.
- Rewrote the generated README for this project, and created empty
  `src/components/` and `logs/` folders.
- `npm run build` and `npm run lint` both pass clean.

Decisions made without asking:

- The repo had no commits at all and the branch was `master`. Since CLAUDE.md
  says to open PRs against `main`, I renamed the branch to `main`, committed the
  three existing docs (CLAUDE.md, business-model.md, tasks.json) as the initial
  commit, and pushed it. Task branches now have a real base to branch from.
- `create-next-app` refuses to scaffold into a folder that already has files, so
  I generated into a temporary subfolder and moved everything up to the repo
  root, then deleted the temp folder and its throwaway git repo.
- `npm audit` reports 3 high-severity advisories, all in transitive dependencies
  of Next.js itself (postcss, sharp). The only "fix" npm offers downgrades to
  Next.js 9, which is not an option. Left alone — worth re-checking when a
  patched Next.js release lands.
